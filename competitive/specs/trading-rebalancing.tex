\begin{ratiobox}
\textbf{Ratio mapping.} Rebalancing is a \emph{control-plane} optimizer that
\emph{proposes} a set of trades; each proposed trade becomes a balanced
transaction the kernel independently checks for conservation before it is
admitted. Tax-lot and asset-location logic read the proven ledger's tax-lot
dimension. A buggy or AI-assisted optimizer can pick the wrong trade (a reviewable
semantic error) but can never produce an unbalanced book.
\end{ratiobox}

\specsection{Conservation \& trust placement}
\textbf{Control plane (proposes) + trusted core (admits).} Optimization is
expressive and external; admission runs through the conservation predicate.
