\begin{ratiobox}
\textbf{Ratio mapping.} Integration is native, not a gated add-on: the
AIP-idiomatic gRPC \texttt{Ledger} API \emph{is} the integration surface, the
core is self-hostable, and data exports use open formats. Connectors are Python
extensions / control-plane adapters. The differentiator is reversibility ---
because the engine is open and the API standard, you are never locked behind a
proprietary integration gate.
\end{ratiobox}

\specsection{Conservation \& trust placement}
