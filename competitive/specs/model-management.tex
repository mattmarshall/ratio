\specsection{Advertised capabilities (feature level)}
\begin{itemize}
  \item N-tier / sleeve model architecture with security-equivalent tracking.
  \item Model marketplace: curated third-party ETF and SMA strategies with automated updates.
  \item Unified Managed Account (UMA) construction and maintenance.
  \item Turnkey / outsourced trading and rebalancing (managed accounts).
  \item Outsourced CIO: manager selection, capital-market assumptions, strategy, risk.
\end{itemize}

\begin{ratiobox}
\textbf{Ratio mapping.} Models, sleeves, and security equivalents are
\emph{content-addressed control-plane artifacts}, frozen per epoch and referenced
by hash, so ``which model produced this allocation, under which version'' is
answerable exactly. The kernel is agnostic to model semantics; it only sees the
balanced transactions a model-driven rebalance proposes.
\end{ratiobox}

\specsection{Conservation \& trust placement}
\textbf{Control plane (declarative).} Pure policy; versioned and auditable, with
no ability to violate conservation.
